# Changelog — aventyrs-core 0.0.80

## New

- `CombatantSheet#overrideInitiative(value, rodadas, started)` — an Iniciativa override restored mid-way, for a
  caller rebuilding a Scene from stored state (`Scene#addParticipant` resets each sheet's Cena, override
  included). `rodadas` counts the Rodadas it still governs, the one in progress included when `started`.
- `Scene#restoreParticipant(sheet, value, group)` — `addParticipant` without `startNewScene()`, for rebuilding a
  Scene around sheets already in the Cena (the twin of `restoreTurnCursor`): their per-Cena logs, charges and
  Iniciativa override survive the rebuild.
- `SkillRoll#getDice()` — the three faces the roll reads.
