# Changelog — aventyrs-core 0.0.55

**Reposicionar and moving on Pontos de Ação exclude each other.** Table ruling (2026-09-24): in
combat, a combatant who has spent Pontos de Ação moving this Turn — an Investida included — can no
longer Reposicionar, and one who has Reposicionou can no longer spend Pontos de Ação moving.

## New

- `TranslatableMessages.REPOSITION_AFTER_MOVEMENT` — `RepositionService#begin` refuses (and
  `canReposition` answers `false`) once `CombatantSheet#getMovementsTakenThisRound()` is non-zero.
- `TranslatableMessages.CHARGE_AFTER_REPOSITION` — `ChargeService#begin` refuses (and `canCharge`
  answers `false`) once `CombatantSheet#getRepositionsTakenThisRound()` is non-zero.

## Callers

- A caller buying an ordinary movement with Pontos de Ação (this core has no mutator for one) must
  refuse it itself while `getRepositionsTakenThisRound() > 0`. Both counters reset at `startTurn`.
