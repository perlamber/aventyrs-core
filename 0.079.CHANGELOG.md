# Changelog — aventyrs-core 0.0.79

**Ego spending — Phase 7: Iniciativa.** Plan in `docs/plans/ego-spending-plan.md`.

## New

- `character.services.InitiativeEgoService` (+`Impl`) — each method pays one Iniciativa point of the type the
  rules put it under (through `useEgoPointsForEffect`; `NOT_ENOUGH_EGO_POINTS`, nothing spent, when it isn't
  there). No timing gate.
  - Temporary: `lowerInitiative(scene, sheet, value, Span)` ("para qualquer valor menor"),
    `rerollInitiative(scene, sheet, newTotal)` (+`Skill.ADVANTAGE_BONUS`, for the Cena), `gainActionPoint`,
    `gainReaction` (this Rodada), `bankRollCharges(sheet, ADVANTAGE)`.
  - Permanent: `setInitiative(scene, sheet, value, Span)`, `setOpponentInitiative(scene, payer, opponent, value)`
    (2 Rodadas), `gainActionSurge` (+2PA, +1 Reação, 2 Rodadas), `bankRollCharges(sheet, DIFFICULTY_REDUCTION)`.
  - `useRollCharge(sheet, roll, charge)` — spends one banked use and marks the roll.
  - `Span` — `RODADA` (the next Rodada's order) or `CENA` (the rest of the Cena).
- `CombatantSheet#overrideInitiative(value, rodadas)`, `#getInitiativeOverride()`, `#advanceInitiativeOverride()`
  — an Iniciativa that replaces the rolled value and every `INITIATIVE` bonus while it holds; dropped by
  `startNewScene()`. `InitiativeEntry#getEffectiveInitiativeValue` returns it.
- `Scene#effectiveInitiativeOf(sheet)`.
- `ego.InitiativeRollCharge` (`ADVANTAGE`, `DIFFICULTY_REDUCTION`; 2 uses per point, dropped with the Cena) and
  `SkillRoll#withInitiativeCharge`/`#hasInitiativeCharge`.
- `TranslatableMessages.INVALID_INITIATIVE_CHANGE`, `NO_INITIATIVE_CHARGE_BANKED`.

## Changed

- `Scene#next()`'s Rodada boundary advances every participant's Iniciativa override before it re-sorts, so an
  override governs exactly the Rodadas it was bought for.

## Rulings / readings

- An order change takes hold at the next Rodada boundary, when the Scene re-sorts — the point every mid-Scene
  Iniciativa change already waits for. "Por uma Rodada" is that next Rodada's order.
- ⚠️ "Reduzir o GD de até duas rolagens" gives no amount — read as 1 nível each, like Sorte's.
- A reroll stands whether higher or lower, for the rest of the Cena.
- "De um PdN" is the Narrador's to judge ("não é recomendada … em combates entre PJs"); core doesn't check it.
