# Changelog — aventyrs-core 0.1.6.21

**Preparação holds a real action.** Until now a Preparação held a free-text description. It now names which action
the caller will run when it fires (table ruling, 2026-10-14):
- Only the Tempo is fixed at preparation.
- Targets and options are asked at firing, and the PM/PD/PV are paid then too.
- An unfired Preparação costs nothing beyond its 3PA.

## Added

- **`sheet.PreparedActionKind`**: TITLE_ABILITY, ACTIVE_ABILITY, MONSTROUS_ABILITY, SPELL, MIMETIZED_SPELL, ATTACK and
  COMPETENCY_ACTION. A plain Perícia roll is not one; the "GM check only" ruling stands.
- **`TranslatableMessages.PREPARED_ACTION_NOT_PREPARABLE`** — the picked action is already a Reação, or a passive with
  nothing to activate.

## Changed (breaking)

- **`PreparedAction`**:
  - `kind`, `key` and `label` replace `description`.
  - `key` is opaque to core: the caller resolves it back to the action when firing.
- **`PreparationService#prepare(sheet, kind, key, label, preparedCost, ctx)`** replaces
  `prepare(sheet, description, preparedCost, ctx)`.
- **`PreparationService#refusalToPrepare`** now refuses a `REACTION` or `NONE` cost. FREE_ACTION and ≤2PA costs are
  still accepted.
