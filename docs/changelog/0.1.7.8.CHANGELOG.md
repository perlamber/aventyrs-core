# Changelog — aventyrs-core 0.1.7.8

**The Efeito de Voo is real, and `FeericoFeat` is wired in full but for Dríade.** Table rulings 2026-10-16: one generic
flight state for every winged source; every flight lands safely as it lapses; Dríade stays TODO; Sentir o Fluxo de
Mana's "identificá-los" is a notice plus a reveal.

## Efeito de Voo — `character.services.FlightService`

- `character.FlightActivation` — one priced flight: source, Tempo de Ativação (`ActionCost`), PD, PM and the Duração
  `Dice` (`null` = unlimited). Value-compared; `FlightService#takeOff` accepts only one it offered.
- Sources (`Feat`/`Race#resolveFlightActivation`):
  - `FeericoFeat#ASAS` — 3PD, or 3PM for a Feérico, −1 per Título; 1d6 + ½Vigor.
  - `FeericoFeat#PIXIE` — Ação Livre, 2PM; 2d6 + ½Carisma + 3 per Título.
  - `DraconicoFeat#ASAS_DE_DRAGAO` — 4PD, −2 per Título; 1d6 + ½Vigor.
  - `Aviano` (Braços Alados) — 1PD; 1d6 + ½Destreza. Silenced under physical racial-trait suppression.
  - `BestialFeat#HERANCA_AVIANA` — 2PA + 3PD; 1d6 + 1 per Herança held (forwarded by `HerancaBestialFeat`).
  - Costs never go below 0. ⚠️ Where no Tempo de Ativação is stated, none is charged.
- Adjustments, applied in this order: `Feat#resolveFlightMagicPointReduction` (`BENCAO_DE_FLORA` −1PM),
  `#resolveFlightDurationOverride` (Benção's 2d6 + ½Foco), `#resolveFlightExtraDurationDice` (`AvianoFeat#CORACAO_ALADO`
  +1d6), `#removesFlightDurationLimit` (`AvianoFeat#ETERNO_VIAJANTE`).
- `FlightService`:
  - `requiresActivation` — true in a Cena de Combate when the holder is on the ground and every source of their Voo is
    priced.
  - `takeOffFreely` — out of combat, or with unpriced Voo (a `GRANTS_FLIGHT` Blessing, a Forma's, `keepsFlying()`).
    Refuses `CANNOT_FLY` / `FLIGHT_ACTIVATION_REQUIRED`.
  - `takeOff(sheet, activation, faces, turn)` — checks the dice before any cost, the PA/Ação Livre entitlement and PD/PM;
    spends PD/PM, takes off and applies a `sheet.FlightEffect`. Returns the Rodadas (`null` if unlimited). PA reported,
    not deducted. Refuses `ALREADY_FLYING` / `FLIGHT_ACTIVATION_NOT_AVAILABLE`.
- `sheet.FlightEffect` lapsing calls `setFlying(false)` (`tickTemporaryEffects`). `setFlying(false)` removes it. An
  unlimited one lands its holder once Desacordado or Caído (Eterno Viajante's "enquanto estiver consciente").

## FeericoFeat

- `ASAS`: "ou personagens recém-criados de raça Feérica" is the starting-slot branch (`isEligibleAtCreation`).
  `isEligible` keeps Aviano/Bestial.
- `PIXIE`, `SIRENIDEO`: "apenas Fadas e Fúrias" now names the two Raças.
- `ESPIRITO_DA_FLORESTA`: "apenas Fadas, Fúrias e Sátiros" now names the three Raças.
- `NINFA`: "do sexo feminino" — new `FeatRequirements#requiredSexo`. An unrecorded Sexo fails it.
- `SIRENIDEO`: breathes underwater (`Feat#allowsUnderwaterBreathing`).
- `FAUNO` / `LUPERCAL`:
  - They now exclude each other (`forbiddenFeat` on both; Fauno's resolved on demand, as a forward reference).
  - GD −1 on Artes/Atenção/Persuasão against an opposed character of Tendência Bondosa (Fauno) / Maligna (Lupercal),
    via `Feat#resolveDifficultyReduction(SkillType, Character, SceneContext)`.
  - ⚠️ Fauno's "Recebe Monstruoso com um tipo de criatura adicional" is read as Monstruoso as an extra prerequisite
    creature type (`getGrantedPrerequisiteCreatureTypes`).
- `ANCIENTEFORME`: Nascidos da Floresta stay +2 Rodadas.
  - `FormaActiveAbility` takes per-holder extra Rodadas.
  - New `ActiveAbility#resolveDurationInRounds(Character)`, used by `ActiveAbilityService` for the `FormEffect`.
    `BarreiraMagicaActiveAbility`'s method of the same name now overrides it, returning `Integer`.
- `SENTIR_O_FLUXO_DE_MANA`: `Feat#resolveSpellcastingSenseRange` (Distância Curta), read through
  `Character#getSpellcastingSenseRange()`. The caller notifies the holder and marks a hidden caster as detected.
- `DRIADE`: left TODO by table decision.
