# Changelog — aventyrs-core 0.1.7.3

**Manual de Criação de Monstros 20261015 — the revision's numbers and mechanics, per Modelo.** Phase 2 of
`docs/plans/monster-manual-v19-revision-plan.md`. Auras come in 0.1.7.4.

New shared pieces:
- `MonstrousAbility#resolveAttackArea` (+ `AttackTargetingService#resolveAttackArea(CombatantSheet, …)`, which
  `AttackDelivery` now asks, so an area bought by an Efeito Ativo passes the entitlement check),
  `#resolveElementalDamageSanctity` (Ascenção's Profano/Sagrado laid over an elemental retype) and
  `#resolveActivationTriggeredEffects` with `ActivationTrigger`, fired by `ActiveAbilityService#activate` and a Título
  activation (`MonstrousAbilityGrant#onActivation`/`#onTitleActivation`).
- `sheet.RecurringDamage` (flat typed damage per Rodada), a sourced `LifeSteal` (renews instead of stacking),
  `DamageScope#excludedSanctity` + `NON_ELEMENTAL_NON_PROFANE_NON_PRIMORDIAL`.
- Correntes in `effect.monstrous`: `MarcaElemental`, `MurcharAbissal`, `TerrorDaFormaVerdadeira`, `AutocontroleLoss`
  (Enfraquecer o Espírito, Carnivoria — Torpor recorded at zero), `Possessao`, `VenenoPrimaveril` (+ its Roubos),
  `RouboDeBonusBase`, `Sanguenomancia`, `SangriaProfana` (+ Roubo de Determinação 2), `MarcaDaEscuridao`,
  `MonstrousCondition` (Títere, Praga Zumbi).
