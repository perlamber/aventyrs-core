# Changelog — aventyrs-core 0.1.6.5

**The Perícia PE discounts are wired.** Cambalacho and the Profissão Excelências now take their PE off store
purchases and forges. They go through the same `EquipmentPointPricing` helper as Barganhista, which floors every price
at 1PE.

## Added

- **`SkillCompetencyAbility#resolveEquipmentPointDiscount(EquipmentPointExpense)`** and
  **`SkillExcellency#resolveEquipmentPointDiscount(EquipmentPointExpense)`**: the competency and Excelência twins of
  the `EgoAdvantage` hook. Both return 0 by default.
- **`EquipmentPointPricing#discounted`** is now a three-source scan. It sums:
  - the Vantagens de Ego;
  - `SkillCompetencyAbility.allFor(holder)`;
  - each trained Perícia's unlocked Excelência tiers.
- **`PersuasaoCompetencyAbility#CAMBALACHO`**: −1PE on PURCHASE and PRODUCTION. Its text states no floor; the shared
  1PE floor applies anyway.
- **`ProfissaoExcellency#FOCADO`** (Graduação 3): −1PE on PURCHASE and PRODUCTION.
- **`ProfissaoExcellency#LENDA`** (Graduação 10): a further −2PE, for "muda para −3PE" in total. This uses the
  codebase's cumulative-tier reading, the same one `ArtesExcellency.LENDA` uses.

Neither discount reaches an Aprimoramento install: the rules say "compra e produção" and "criação e compras". All the
discounts stack with Barganhista's.
