# Changelog — aventyrs-core 0.0.63

**Flight, swimming and climbing** (plan Phase C). "Movimento Base de Voo / de Natação / Vertical"
are now real movement modes beside land Movimento, each with its own figure per Ponto de Ação.
Feat TODO lines: 281 → 274.

Rules reading: ⚠️ most clauses grant a mode with no figure ("possui Movimento Base de Voo"). Such
a mode is worth the character's land Movimento Base, per Polimorfismo's Draconato ("Movimento
Base de Voo igual à sua velocidade em terra").

Whether a character is flying or swimming *right now* is still the caller's
`EnvironmentalState#flying`/`atLeastHalfSubmerged`. Flying as a timed state (a PD cost and a
Duração) is not modelled.

## New

- `character.MovementMode`: `LAND`, `FLIGHT`, `SWIM`, `CLIMB` (Vertical / escalada).
- `MovementService`:
  - `hasMovementMode(CombatantSheet, MovementMode)`: `LAND` always; another mode when a Raça,
    Talento, Habilidade de Competência or worn Forma grants it;
  - `hasMovementMode(Character, MovementMode)`: the Forma-blind version;
  - `getMovementBase(CombatantSheet, MovementMode)`: 0 without the mode. Otherwise it starts from
    a Talento's absolute figure (the largest), or else the land Movimento Base. Then it adds
    Talento/Raça increases and item bonuses. Floored at 0.
- `Feat#grantsMovementMode(mode, character, holder)`, `Feat#resolveMovementBaseOverride(mode,
  character)` (a figure; for `LAND` it replaces the size-table figure), and
  `Feat#resolveModeMovementIncrease(mode, character)`.
- `Race#grantsMovementMode(mode)` and `Race#resolveModeMovementIncrease(mode)`. Both are silenced
  while a Forma suppresses physical racial traits.
- `SkillCompetencyAbility#grantsMovementMode(mode)`.
- `ModifierType.FLIGHT_MOVEMENT`, `SWIM_MOVEMENT`, `CLIMB_MOVEMENT`: item bonuses to a mode's figure.

## Now real

- **Raça:** `Aviano` flies (Braços Alados). A Rapinante flies +2UD, a Correnuvens +1UD.
- **Voo:** `AvianoFeat#CORACAO_ALADO` (+2UD per Título), `#BRACOS_LIVRES` (−3UD; ⚠️ its hands half
  is still unbuilt, so only the price applies), `DraconicoFeat#ASAS_DE_DRAGAO`, `FeericoFeat#ASAS`
  (+2UD), `FeericoFeat#PIXIE` (8UD), `BestialFeat#HERANCA_AVIANA`.
- **Natação:** `FeericoFeat#SIRENIDEO` (6UD, and land Movimento set to 2UD),
  `BestialFeat#HERANCA_ANFIBIA`, `AtletismoCompetencyAbility#ANFIBIO`.
- **Vertical:** `BestialFeat#HERANCA_REPTILIANA`, `AtletismoCompetencyAbility#ALPINISTA_VELOZ`.
- **Forma:** Metamorfose Dracúlea's Aranha Gigante (Vertical) and Morcego Atroz (Voo), while worn.
- **Items:** `BootsItem#BOTINAS_DE_ESCALADA` (+2UD Vertical) and `#NADADEIRAS_DECIEMBRANAS` (+2UD
  Natação). ⚠️ These are read as raising a mode the wearer already has, not granting it.
- `HerancaBestialFeat` forwards `grantsMovementMode`.

## Changed

- `MobilidadeFeat#INVESTIDA_AQUATICA`'s −1PA on an Investida now applies only to a holder with a
  Movimento Base de Natação, as written. It was granted to everyone before.
- `ElficoFeat#GUARDIAO_DAS_NUVENS`: the TODO claiming its Vantagem was withheld was stale (it
  already read altitude and flight). Only the "mimetizar Voo" half is left.

## Callers

- To move a character through the air, water or up a wall, price the movement with
  `getMovementBase(sheet, MovementMode.X)`, and refuse it when `hasMovementMode` is false.
- `BootsItem`'s two Favores now carry an `ItemBonus`. A test that asserted an empty bonus list
  must look at the new `ModifierType`s.
