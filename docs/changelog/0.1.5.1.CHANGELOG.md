# Changelog — aventyrs-core 0.1.5.1

**Previewing an attack's Efeitos** — a sheet screen can list what each weapon carries beyond its damage.

## New

- **`combat.AttackEffectsPreview#of(holder, attackSkill, attackSource, sceneContext)`** — asked before any roll, the
  same sources `AttackDelivery` chains on a landed hit: `criticalEffects()` (the source's own Efeito Crítico or a
  Título's override, repeated by Finalização, then each Título's additions), `hitCriticalEffects()` (Finalização's
  repetitions on a plain hit), `effectChains()` (Títulos', Talentos' and a foe's stat block's Correntes) and
  `criticalEffectChains()` (stages added on an Acerto Crítico regardless of the Corrente threshold — Arte do Escudo
  Atacante's Rugido, Abrir Defesas). No target, roll or request is known, so target-scoped and roll-activated clauses
  (Golpe Sobrenatural's Escancarar Defesas, Golpe Trovejante's doubling, an `EmpoweredAttack`'s addition) are absent.

## Internal

- `CriticalEffectResolver#typesOf` holds the identity list `resolve` builds from; behaviour unchanged.
