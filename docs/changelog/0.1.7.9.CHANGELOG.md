# Changelog — aventyrs-core 0.1.7.9

**`ActionProfile#CONSCIENCIA_DEFENSIVA` is real.** "Em seu primeiro movimento de cada Rodada, nos 2 primeiros UD
percorridos, você não provoca Reações. Em Rodadas ímpares nenhum de seus movimentos provoca Reações." Table rulings
2026-10-16: odd Rodadas are the counter as shown (1, 3, 5…), so the opening Rodada 0 is even; the 2UD are hexes
travelled, so a Terreno Difícil hex counts once; a hostile still in reach once the window closes reacts at its next
covered hex.

## The profile's movement hooks

- `ActionProfile#resolveReactionFreeSteps(movementIndex)` — hexes at the start of that movement of the Rodada that
  provoke nothing (`FIRST_MOVEMENT_REACTION_FREE_STEPS` = 2 for movement 0). Default 0.
- `ActionProfile#exemptsMovementFromReactions(manoeuvre, ctx)` — the whole movement provokes nothing (any movement on
  an odd combat Rodada). Default `false`.
- `Manoeuvre#isMovement` — an ordinary movement (`null`), Investida, Encontrão and every `ActionKind.MOVEMENT`
  manoeuvre. Levantar-se is not one, so it still provokes.
- `SceneContext#isOddCombatRound()`; `DefeitoFeat`'s odd-Rodada helper now reads it (same answer as before).

## `MovementReactionService`

- `action.MovementProgress(movementIndex, stepsTravelled)` — where a route starts among the mover's movements, supplied
  by the caller, since this core records no movement's path. `startOf(index)` for a fresh movement.
- New longest `getRouteCheckpoints(…, knownReachUd, MovementProgress)` and `getProvokedReactors(…, chargeTarget,
  MovementProgress)`; the shorter forms pass `null` (no window). Step k enters position k. With f free steps the first
  position that may provoke is index f, unless the route ends there. A route no longer than the window provokes
  nothing in it.
- The odd-Rodada exemption joins `isExempt`, beside the held exemptions, so every form sees it.
- `getHostilesInReach(subject, at, ctx, positions, knownReachUd)` — who has a combatant in melee reach where it stands,
  with **no** movement exemption. It is what Impedir Conjuração asks; casting is not a movement.
- `ChargeService#begin` passes the charge's own movement index, so an Investida that is the Rodada's first movement
  provokes nothing from where it starts.

## A silent foe has no Perfil de Ação

- `MonsterTemplate.DEFAULT_ACTION_PROFILE` is now `null`. `Character#actionProfile` is no longer `@NonNull`. The PA,
  Reação, Ação Livre and skill-roll-cost readers treat `null` as no adjustment, and the movement judge treats it as
  no exemption.
  Before this, every foe whose stat block names no Perfil de Ação would have gained Consciência Defensiva.
- `CharacterFixture`'s templates carry no profile either.
