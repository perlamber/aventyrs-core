# Changelog — aventyrs-core 0.1.6

**Talento Atributo prerequisites count the Bônus Racial.** Table ruling, 2026-10-09.

## Changed

- **Every Atributo clause of `FeatRequirements`** — `attributeDomain`/`requiredAttributeValue`, the
  `maximumAttributeDomain` ceiling, `requiredAnyAttributeValue` and `requiredAnyRacialAttributeValue` — now tests
  Base plus the race's Bônus Racial (fixed and chosen), not Base alone. An Anão with Vigor Base 3 and a racial +1
  qualifies for `SobrevivenciaFeat#VITALIDADE` ("Vigor 4"). A Variável bonus and a Talento's own Atributo grant
  (`Feat#resolveAttributeBonus`) still don't count.

## Added

- **`AttributeValue#getBaseWithRacialBonus()`** — Base + `getRacialBonus()`, what those clauses read.

## Unchanged

- The Habilidade de Atributo slot floor (`AttributeAbilityService`, `ConselheiroDeGuerraYmirianoFeat#of`,
  `HabilidadeDeAtributoEscolhidaFeat#of`), the Graduação cap and `CharacterAttributeService#upgradeBase` still read
  Base alone.
