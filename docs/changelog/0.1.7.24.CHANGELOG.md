# Changelog — aventyrs-core 0.1.7.24

**Talento grants count toward Atributo Pré-requisitos** (table ruling, 2026-10-17). A Talento's Atributo
Pré-requisito now reads Base + the race's Bônus Racial (the 2026-10-09 ruling, unchanged) **plus** every held
Talento's permanent `Feat#resolveAttributeBonus` grant — a Herança Bestial's "+1 de bônus racial", Mestre Vampiro's,
Vigor Trollico's. The Variável part, Equipamento and round-scoped bonuses still never count.

## New

- **`Character#getPrerequisiteAttributeValue(AttributeDomain)`** — the one figure every `FeatRequirements` Atributo
  clause reads (the floor, the ceiling, the domain-less "Atributo N ou superior"), and Prodígio's floor.

## Changed

- A ceiling clause (`maximumAttributeDomain`) now counts a held Talento's grant too, so a grant can push a character
  past it.
- `MonstruosoFeat#ALFA`-style "Atributo com Bônus Racial" clauses still also require an actual racial bonus on that Atributo.
