# Changelog — aventyrs-core 0.0.77

**Ego spending — Phases 1–4: Recursos.** Plan in `docs/plans/ego-spending-plan.md`.

## New

- `ego.SocialClass` — the Recursos tables, rows 0–5 (Falência … Alta Nobreza): PE iniciais, PE per temporary /
  permanent point, Raridade Inicial (`Optional`, empty at 0), and the Utilidades e Serviços columns as reference
  data only. `SocialClass.of(int)` (clamped 0–5), `SocialClass.current(sheet)` (permanent Recursos left),
  `getPointValue(EgoPointType)`, `isExtremePoverty()`.
- `CharacterCreationService#grantStartingEquipmentPoints(sheet)` — the row's PE iniciais into the wallet, once,
  at the end of creation. `#getStartingStore(character)` — an `ItemStore` at the Raridade Inicial (empty at 0).
- `EgoPointsService#spendResourcesForEquipmentPoints(sheet, type, amount)` — spends Recursos through
  `useEgoPointsForEffect` and pays PE into the wallet, each point priced at the row it was spent from (a
  permanent point lowers the next one's row). No timing gate.
- `Feat#resolveResourcesPointValueBonus(Character)`; `QualidadeFeat#DESTINADO_A_FORTUNA_MENOR` (Saber
  Investir) returns +2.
- `TranslatableMessages.RESOURCES_NOT_RECOVERED_BY_SESSION`.

## Changed

- **A permanent Ego spend keeps the temporary points still held** (all four Egos): held = min(held, new
  ceiling). `EgoPointPool#spendPermanent` takes the same amount back off the temporary spent count. Both
  extremes of the Sorte 3 example (6 / 3) are unchanged; a part-spent Ego keeps more than before.
- `EgoPointsService#applySessionRecovery` refuses `RECURSOS` as the chosen Ego (the bulk form before anyone
  recovers), and a Vantagem's extra never lands in Recursos.

## Rulings / readings

- The row is the Recursos a character still holds permanently — the book's "valor total" ("Recursos 5 (3
  disponíveis)"); an extra past 5 is worth row 5.
- Table ruling (2026-09-30): the example's closing text is "Recursos total 4 (1 disponível)" (`ego.txt` had
  "2 disponíveis"); it is what pins the permanent-spend rule above.
- Starting PE read the finished character's Recursos, capped at 5 (Antecedentes and Privilegiado included).

## Consumer notes

- The end-of-session modal must not offer Recursos.
