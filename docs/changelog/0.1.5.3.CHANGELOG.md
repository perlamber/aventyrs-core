# Changelog — aventyrs-core 0.1.5.3

**Autoconhecimento grants its Vantagem de Ego.**

## New

- **`feat.VantagemDeEgoEscolhidaFeat`** — the acquired form of `DestinoFeat#AUTOCONHECIMENTO`, carrying the
  Vantagem picked. `of(holder, advantage)` validates; `optionsFor(holder)` lists every Vantagem of an Ego whose
  **total** value is 2 or more, bar the ones already held (Moral Herdada once per Fama); `chosenBy(character)`.
  Table rulings (2026-10-08): the Ego's total counts, and the Vantagem stacks beside the creation one of the same
  Ego.
- **`DestinoFeat#AUTOCONHECIMENTO#resolveRequiredChoices`** — one `EgoAdvantage` pick, so the bare constant is
  refused with `FEAT_REQUIRES_CHOICE`.
- **`Feat#getGrantedEgoAdvantages(character)`** — Vantagens a Talento grants on top of the creation ones.
- **`Character#getAllEgoAdvantages()`** / **`#getEgoAdvantages(EgoDomain)`** — creation Vantagens plus granted
  ones; several may share an Ego.
- `TranslatableMessages#CHOSEN_EGO_ADVANTAGE_NOT_AVAILABLE`.

## Changed

- Every Vantagem scan reads `getAllEgoAdvantages()`: Perícia roll bonuses, damage and critical bonuses, Iniciativa
  blessings, item pricing, Herança Familiar's starting-equipment check. `EgoPointsService`'s session recovery and
  spend recovery sum over the Ego's Vantagens and its spend blessings concatenate; Resoluto is found among the
  Autocontrole ones. `Character#getEgoAdvantage(EgoDomain)` still answers the creation one alone.
