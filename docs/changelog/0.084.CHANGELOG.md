# Changelog — aventyrs-core 0.0.84

**Inteligentes.** One classification for every clause naming "inteligentes".

## New

- `CombatantSheet#isIntelligent()` / `#setIntelligent(boolean)` — table ruling (2026-09-30): every character is
  intelligent; a foe only when the Narrador opts in. Defaults to true on a sheet.
- `MonsterBlueprint#intelligent` (builder, default false) and `MonsterTemplate#isIntelligent()` (default false) —
  a `MonsterSheet` takes its flag from them; one restored from bare numbers is not intelligent.

## Changed

- **Efeitos de Ego — "apenas PdN Exemplares (quando inteligentes)"**: `MonsterSheet#checkEgoEffectAvailable` also
  refuses an Exemplar not marked intelligent, and `EgoPointsService#useEgoPointsForEffect` refuses a PdN held as a
  plain sheet that is not intelligent (both `MONSTER_EGO_EFFECTS_EXHAUSTED`).
- **Fingir Fraquezas** (`FingirFraquezasInteraction`) binds only intelligent enemies. ⚠️ Its Defesas bonus and PD
  price still count every enemy in range — "1+ Número de Inimigos" names no intelligence.
- **Exibicionista** (`PeritoFeat`) counts intelligent neutrals as its plateia (was: any `CharacterSheet`).
- **Aparência Inofensiva** (`DestinoFeat`): its "inimigos inteligentes" TODO now points at `isIntelligent()`; the
  targeting step it needs still doesn't exist.
