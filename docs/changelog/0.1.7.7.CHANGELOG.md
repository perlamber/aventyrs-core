# Changelog — aventyrs-core 0.1.7.7

**Prodígio, Genialidade and Genialidade Desperta ask for their Habilidade.** The three `DestinoFeat` constants
served by `HabilidadeDeAtributoEscolhidaFeat` now declare `resolveRequiredChoices` — a `FeatChoice<AttributeAbility>`
— so a client offers the pick and `FeatService#grantFeat` refuses the bare constant (`FEAT_REQUIRES_CHOICE`).

- `HabilidadeDeAtributoEscolhidaFeat#optionsFor(holder, talento)`: every Habilidade of each qualifying Atributo, less
  those held; Perito Teórico and Magia Alternativa are offered in their resolved forms (`PeritoTeoricoAbility`,
  `MagiaAlternativaAbility`).
- Table ruling 2026-10-16: **Prodígio's floor is "Base 2 ou superior"**, read as Base + Bônus Racial
  (`#meetsFloor`), below the Base 3 a first slot needs; it is also the Talento's prerequisite
  (`requiredAnyAttributeValue(2)`). Genialidade and Genialidade Desperta keep the Base 3 floor.
- A granted Habilidade applies only its passive / `resolve*` hooks — not `AttributeAbilityService`'s acquisition
  side-effects (Charme's per-Perícia picks, Rato de Biblioteca's training, Destino Favorável's Ego point).
