# Changelog — aventyrs-core 0.0.87

**Sincretismo Religioso and Falsa Devoção** — more than one Divindade.

## New

- `DevotoFeat#SINCRETISMO_RELIGIOSO`: "uma segunda Divindade … considerado um Devoto de ambas". The second Divindade
  counts genuinely, so its Talentos de Devoção read the character's own tier.
- `DevotoFeat#FALSA_DEVOCAO`: "considerado Devoto Adepto da divindade escolhida". The feigned Divindade's Talentos de
  Devoção read exactly Adepto. It is tagged Especialista.
- `feat.ChosenDeityFeat` — the acquired form of both, carrying the chosen Divindade.
- **On `Character`:**
  - `#getGenuineDevotions()` — the character's own Divindade plus any Sincretismo one;
  - `#getFeignedDevotions()` — the Falsa Devoção one;
  - `#getDevotedDeities()` — both together.
- `DevotoFeat#tierFor(holder)` — the tier a Talento's rungs read, per Divindade.

## Changed

- "Devoto de X" (`FeatRequirements#requiredDeity` / `#requiredDeityCategory`) now accepts any Divindade the character
  is devoted to, genuinely or falsely.
- `DevotionService` owes and records rung picks against `tierFor`, so a feigned Divindade asks only Adepto's.
- `DevotoFeat#isUmbral(Character)` reads every devoted Divindade.

## Still open

- Sincretismo's "custa apenas 1EXP para Homens-Fera" — a Raça's Talento cost sees no Talento's pick.
