# Changelog — aventyrs-core 0.1.6.2

**Alma de AEther's negation is real.** Table ruling, 2026-10-10: the holder is asked on every Magia that reaches
them, and only a use spends it — until the next combat.

## Added

- **`SpellCastingService#canNegateSpell(caster, target, sceneContext)`** — whether target may negate a Magia caster
  cast on them right now: a held Talento answers `Feat#offersSpellNegation`, inside a Cena de Combate, and never for
  the target's own Magia. Ask once the Magia is known to land (an attack-delivered one has hit), before anything of it
  is applied.
- **`SpellCastingService#negateSpell(caster, target, manaSpent, sceneContext)`** — claims the use
  (`Feat#onSpellNegated`) and recovers `manaSpent` PM, no more than target has spent; returns what came back. Throws
  `SPELL_NEGATION_NOT_AVAILABLE` when `canNegateSpell` says no. The caller then applies nothing of that Magia to the
  target — damage, effect, Corrente and casting critical alike ("negar o Efeito": a Magia's damage is part of its
  Efeito).
- **`Feat#offersSpellNegation` / `Feat#onSpellNegated`** — the hook pair, shaped like Pronto para Ação's relief.
- **`QualidadeFeat#ESCOLHIDO_DA_MAGIA_MAIOR`** implements it on the per-combat ledger
  (`CombatantSheet#markAffectedThisCombat`), so `CombatantSheet#endCombat()` re-arms it.
