# Changelog — aventyrs-core 0.1.7.16

**`AttackDelivery` applies níveis to a flat Defesa.** Closes the TODO on the class: the attacker's GD reduction is no
longer only reported. Table ruling 2026-10-17: a nível moves a flat Defesa as **tier + excess**. The Defesa is read as
the tier it reaches plus what it has over that tier's base, the tier shifts, and the excess stays. This is the shape a
foe's Defesa is built in (Esquiva e Aparar GD + modifiers).

## `DifficultyLevel#shiftValue(value, steps)`

- Positive steps are harder, negative steps easier. Médio+2 (20): −1 → Fácil+2 (16), −2 → Muito Fácil+2 (14),
  +1 → Difícil+2 (25).
- The end tiers clamp, so a Defesa already in Muito Fácil (12–13) is not eased further. A value below 12 reaches no
  tier and is returned unchanged.

## `AttackDelivery`

- Each target's `requiredTotal` is its flat Defesa + the Aptidões Mágicas' DM + a defence Favorecido, shifted by
  (that defender's `Feat#resolveSpellResistanceDifficultyReduction` − the attacker's `difficultyReduction`).
- What this makes real on this path: the Excelências' níveis, `AssassinoFeat#SAQUE_RELAMPAGO`,
  `EscudeiroFeat#ARTE_DO_ESCUDO_ATACANTE`, Escancarar Defesas, Estudar Defesas, Sorte's GD reduction, Iniciativa's
  charge, Transferir Rancor, the Totem de Gaea, and the Defesa side of Artesão de Barreiras and Aptidão Mágica Suprema.
- A target-scoped nível (Escancarar, Estudar) is judged against the primary target and so reaches the additional
  targets as well. Every target-conditioned roll hook has the same limit.

## `DeliveredAttack#difficultyReduction`

- Níveis the caller adds to the attack, on top of the roll's own. Use it for an `EmpoweredAttack#difficultyReduction`
  (Fúria dos Deuses), which core reports and never sees again. It is summed into the same shift.

## Breaking: `DeliveredAttackResult`

- `getUnappliedDifficultyReduction()` → `getDifficultyReduction()`, and `getUnappliedSpellResistanceReduction()` →
  `getSpellResistanceReduction()`. Both are now reported **already applied**, for display only.

## Not changed

- The direct skill-roll path (`AbstractSkillInteraction#easedTarget`) still snaps a flat target to its tier's base,
  dropping the excess. That is a different reading of the same rule, and it is left as it was.
