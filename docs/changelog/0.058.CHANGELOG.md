# Changelog — aventyrs-core 0.0.58

**Arcanista is fully wired.** `MetamagicoFeat#ARCANISTA` now lets its holder know as many
Árvores de Magia as their Conhecimento Metamágico. Each Árvore comes with its Semente, and the
first two Brotos are free. Each later ladder rung makes its own two picks free: Mudas,
Emergentes, Florescentes. Nothing records the picks. Known trees, free picks and branches are all
derived from `Character#getSpells()`, so no API schema changes.

Ruling (table, 2026-09-25): "Conhecimento Metamágico" is the Conhecimentos roll value
(Graduação + Gnose), not the Graduação alone.

## New

- `magic.FreeSpellPick(BranchLevel rung, int picks)`: free Magias a Talento hands out at one
  rung, each from a different Árvore.
- `Feat#resolveKnownTreeCapacity(Character)`: how many Árvores the holder may know. Default 0.
- `Feat#resolveFreeSpellPicks(Character)`: the free picks a Talento owes. Default empty.
- `SpellService#getKnownTreeCapacity`: the sum of the capacity hook across Talentos.
- `SpellService#getOpenTreeSlots`: capacity minus the trees already known, floored at 0.
- `SpellService#getLearnableTrees`: the trees that can still be opened.
- `SpellService#learnTree(character, sheet, tree)`: opens a tree and grants its Semente(s).
- `SpellService#getOwedFreeSpells`: per rung, how many free picks are still owed. It counts
  distinct Árvores already holding that rung.
- `SpellService#getFreeSpellOptions(character, rung)`: the Magias that can fill an owed pick. In
  a diverging tree both ramificações are offered, so the pick is also the branch choice.
- `TranslatableMessages.SPELL_TREE_CAPACITY_REACHED`.
- `MetamagicoFeat`:
  - `ARCANISTA` gets tree capacity plus 2 free Brotos;
  - `ARCANISTA_EXPERIENTE`, `MESTRE_ARCANISTA` and `DESAFIADOR_DA_REALIDADE` each get 2 free
    picks at the rung they unlock.

## Changed

- `SpellService#getAcquisitionCost` also waives a Magia that spends an owed free pick.
- `SpellService#grantSpell` refuses a Magia of a not-yet-known Árvore when no tree slot is open
  (`SPELL_TREE_CAPACITY_REACHED`).
- The `Feat#grantsFreeSpellAcquisition` javadoc no longer says ARCANISTA is waiting on it.

## Callers

- **A character without ARCANISTA can no longer learn any Magia** through `grantSpell`. Mimetized
  Magias are unaffected.
- After creation, and after any Talento grant or raised Conhecimentos/Gnose, ask
  `getOpenTreeSlots` and `getOwedFreeSpells` and prompt for the picks. Replay them with
  `learnTree` and `grantSpell`.
- `Character#grantSpell` (the raw mutator) still bypasses every gate, as before.
