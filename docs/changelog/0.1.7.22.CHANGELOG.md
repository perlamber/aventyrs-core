# Changelog — aventyrs-core 0.1.7.22

**MobilidadeFeat wiring, Phase 5: INVESTIDA SELVAGEM's movement RD, SOLAR and LUNAR.** Every MobilidadeFeat constant
is now wired; the class carries no TODO.

## New

- **`ChargeService#openMovementWard` / `#closeMovementWard`** — the charger's movement RDS as an open-ended bonus
  sourced `ChargeService.MOVEMENT_WARD_SOURCE`, opened as the charge's movement begins and closed by the caller.
- **`ChargeService#applySavageAftermath(sheet, chargeWeapon, enemiesHit, enemiesDamaged)`** and
  **`Feat#resolveChargeAftermathEffects`**.

## Talentos now real

- **Investida Selvagem** — "durante o movimento da investida" RDS is applied, one instance per Título held.
- **Investida Selvagem Solar** — with 3+ enemies damaged: Defesas +1 + Bruto Títulos (+ enemies hit with a MEDIUM/HEAVY
  Escudo equipped), for as many Rodadas as enemies hit.
- **Investida Selvagem Lunar** — the same trigger: Roubo de Vida 1 + Bruto Títulos (+1 with a MEDIUM/HEAVY charge
  weapon), for as many Rodadas as enemies hit.
