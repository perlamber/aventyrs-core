# Changelog — aventyrs-core 0.1.6.22

**Manual de Criação de Monstros v19 (20261013) imported.** `docs/rules/criacao-de-monstros.txt` now holds the new
revision. Its main addition is the Modelo **Escolhido de Macária** (undead), which the REANIMAR invocation work builds
on (`docs/plans/undead-invocation-plan.md`). The shorthand outlines that follow it (Caminhante Umbral … Extra-planar)
and the empty Modelo headers are design notes, not rules, and are not implemented.

## Changed

- **`AlmaElementalAbility`**: Fúria Elemental, Aura Elemental and Tormenta Cataclísmica quote "Dano **Físico**
  Elemental", as the new text does. None of them types damage in code yet, so no behaviour changes.
- **`AspectoHumanoideAbility#FORMA_VERDADEIRA`**: Terror da Forma Verdadeira now progresses to "Amedrontado". That is
  not a defined Condição, so it is read as Assustado (table ruling, 2026-10-14). The Corrente itself is still
  unapplied.
- **`MonsterRules#ABILITY_POWER_DEGREE_STEP`**: the javadoc quotes "uma nova Habilidade Monstruosa". The rule was
  already implemented that way.
