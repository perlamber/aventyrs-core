# Changelog — aventyrs-core 0.0.99

**Habilidades de Competência, Phase 0** — the core half of `docs/plans/skill-competency-wiring-plan.md`'s client plumbing.

## Changed

- **Dom Bárdico reaches every ally in the Scene.** Its Blessing now carries `reaching(Range.AO_ALCANCE_DOS_OLHOS)`
  — "seus aliados" names no distance (ruling). Before, it had no reach, so a caller resolving allies by reach
  granted it to no one.
- **Dom Bárdico counts however it was come by.** `ArtesInteraction` checks `SkillCompetencyAbility#allFor`, so a
  Talento-granted copy works too.
- **`ArtesAprimorarComArteAbility` is equal by its chosen Perícia** (`@EqualsAndHashCode`). An instance rebuilt
  from the wire now matches the one held, so `allFor`'s deduplication and a remove-by-equality both work.
