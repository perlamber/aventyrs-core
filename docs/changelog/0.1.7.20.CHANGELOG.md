# Changelog — aventyrs-core 0.1.7.20

**MobilidadeFeat wiring, Phase 3: MOVIMENTO FURTIVO's price and MOVIMENTO ACROBÁTICO.**

## New

- **`Feat#halvesCurrentMovementBase(Character, CombatantSheet)`** — a live-state halving, in the sheet overload's last
  stage beside Caído and Passos Reduzidos (once however many say so). It does not default to the permanent
  `halvesMovementBase`.
- **`Manoeuvre#MOVIMENTO_ACROBATICO`**, exempt from movement Reações like Reposicionar.
- **`RepositionService#canMoveAcrobatically` / `#getAcrobaticDistance` / `#beginAcrobatic`**, and
  `TranslatableMessages.ACROBATIC_MOVEMENT_NOT_HELD` / `ACROBATIC_MOVEMENT_ALREADY_USED`.

## Talentos now real

- **Movimento Furtivo** — Movimento Base halved while Escondido, unless the holder has 7+ Graduações em Furtividade.
- **Movimento Acrobático** (table ruling 2026-10-17) — taken in place of a Reposicionar: the same Ação Livre and
  refusals, claiming that Reposicionar (so it excludes Pontos de Ação movement), once per Rodada, reaching half the
  Destreza total plus 2UD per Título held, provoking no Reações.
