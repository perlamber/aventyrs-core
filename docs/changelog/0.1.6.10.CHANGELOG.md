# Changelog — aventyrs-core 0.1.6.10

**The damage taxonomy is updated.** The table dropped Físico-Elemental (2026-10-12). The types are now Físico,
Primordial, Elemental, Mágico Elemental, Físico/Mágico Profano, Físico/Mágico Sagrado, Físico/Mágico Umbral, Danos
de Queda and Danos de Asfixia. The core models them as **nature × qualifier**: the `DamageType` nature, plus an
element or a `DamageSanctity` on the `DamageDescriptor`.

## Rulings (table, 2026-10-12)

- **Elemental** replaces Físico-Elemental. It stays RE-only: RD never reaches it.
- **Mágico Elemental** takes RE, RM and RDS.
- **Mágico is always qualified.** A `DamageDescriptor` refuses a Mágico hit with neither an element nor a sanctity.
- **Danos de Queda and Danos de Asfixia** take only RA until their rules arrive: no RD, RDS, RM, RE, sanctity
  reduction, Pele de Pedra or Meio-Dano.
- Cura Mortis' Necrofagia is **Primordial**. Golpe Sobrenatural is **Mágico Profano**.

## Breaking changes

- `DamageType`:
  - `FISICO_ELEMENTAL` is removed.
  - The old `ELEMENTAL` (the rules' "Mágico Elemental") is now `MAGICO` plus its element. The old
    `FISICO_ELEMENTAL` is now `ELEMENTAL`.
  - New constants: `QUEDA` and `ASFIXIA`.
  - New helpers: `requiresElement`, `admitsElement`, `takesOrdinaryMitigation` and
    `isReducedOnlyByAbsoluteReduction`.
- `DamageSanctity` adds `UMBRAL`. No reduction of Umbral exists yet, so `getSanctityDamageReduction` returns 0 for it.
- `DamageDescriptor` and `DamageBonus` validate the new pairings:
  - an element is required for `ELEMENTAL`, allowed for `MAGICO` and refused otherwise;
  - `MAGICO` must carry an element or a sanctity.
- `DamageScope`:
  - `PHYSICAL` is `{FISICO}`. An Elemental hit is no longer Físico.
  - `element()` covers `ELEMENTAL` and `MAGICO`.
  - The new `elementFree` component keeps a Mágico Elemental out of `NON_ELEMENTAL_NON_PRIMORDIAL`.
- `SpellDamage`:
  - `halfFocusMagicalElemental` covers "Dano Mágico Elemental" (7 Magias).
  - `halfFocusElemental` now means "Dano Elemental", with no Mágico (Olhar de Eldur).
  - `halfFocusMagical` is replaced by `halfFocusPrimordial`.
- `DamageReceipt` carries the hit's `elementalType`. `isElemental()` is true for an Elemental hit or any hit naming
  an element.

## Added

- `DamageInteraction#withElement(ElementalType)`, and a longest `DamageService#calculateFinalDamage` that takes a
  `DamageDescriptor`. On the attack path, a hit with an element or sanctity is now mitigated as a full descriptor in
  one pass. That pass includes RE and element-scoped immunity against a Mágico Elemental attack.
- `docs/rules/defesas-e-resistencias.txt` gains a "Tipos de Dano" section that records the update.

## Changed

- Every "Físico Elemental" in `docs/rules` and in the quoted rules text in code now reads "Elemental".
- Mágico Elemental hits (the 7 Magias, Olhar de Lacerto, the summon comet and burst, Sopro and Aura Elemental,
  Cataclismo Elemental's burst) now take RM as well as RE.
- A Mágico hit's sanctity is mitigated inside `DamageService`, alongside every other stage. It is no longer applied
  as a separate step after Meio-Dano.
