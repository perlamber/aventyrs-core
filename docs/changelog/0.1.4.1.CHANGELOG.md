# Changelog — aventyrs-core 0.1.4.1

**Herança Familiar** — the Vantagem de Recursos is real.

## New

- **`CharacterCreationService#isFamilyHeirloom(ItemSpecification)`** — an Equipamento Ofensivo of any purchasable
  Raridade (not capped by the Raridade Inicial), fabricated as an Obra-Prima Ofensiva no rarer than
  `FAMILY_HEIRLOOM_MAX_MASTERPIECE_RARITY` (Incomum), with no Aprimoramentos and no Regalia grade. The Obra-Prima is
  required.
- **`CharacterCreationService#grantFamilyHeirloom(CharacterSheet, ItemSpecification)`** — forges it into the
  inventory for no PE. Called once, at creation, like `grantStartingEquipmentPoints`.
- **`TranslatableMessages.FAMILY_HEIRLOOM_NOT_HELD`**, **`INVALID_FAMILY_HEIRLOOM`**.

## Still open

- Equipamentos Tecnológicos have no catalog entries, so their exclusion holds without a check.
