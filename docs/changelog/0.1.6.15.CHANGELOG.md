# Changelog — aventyrs-core 0.1.6.15

**Resistances shorten continuous effects.** This is Phase 2 of `docs/plans/acoes-de-combate-plan.md`. RD, RM, RE and RA
each carry a Duração clause: "Reduz a Duração de Efeitos … contínuos em -1 Unidade (a redução de Duração não se acumula
entre instâncias)".

## Added

- **`sheet.ContinuousNature`** declares what a harmful continuous effect is: its `DamageDescriptor` and whether it
  deals damage. Effects declare it through **`TemporaryEffect#getContinuousNature()`**, which is `null` by default, so
  nothing else is touched. These effects declare one:

  | Effect | Nature |
  |---|---|
  | `Bleeding` | Físico |
  | `Withering` | Físico Profano |
  | `VampiricVenom` | Mágico Profano |
  | `Poisoning` | Elemental Natural; damaging only while it deals damage |
  | `RecurringDice` | its descriptor, for damage only |
  | `ManaDrain`, `DeterminationDrain` | untyped (only RA reaches them) |

- **`character.services.ResistanceDurationService`** (+`Impl`) works out how many Rodadas come off:
  - **RD** takes one from a damaging Físico effect that isn't Primordial.
  - **RM** takes one from a Mágico effect that isn't Primordial.
  - **RE** takes one from an effect of the element it resists (Mágico Elemental included).
  - **RA** takes one from any declared effect.
- **`DamageService#holdsResistance(target, Resistance, descriptor, ctx)`** answers "at least one instance right now".
- **`CombatantSheet#applyEffect`** shortens a finite declared effect once, as it lands. An effect brought down to 0
  Rodadas never takes hold. Open-ended effects such as `Burning` are untouched.

## Readings (not table rulings)

- ⚠️ Each matching resistance takes its own Unidade, so RD and RA together cut a Sangramento by 2. The text only
  forbids stacking "entre instâncias" of one resistance.
- ⚠️ RA reaches a Primordial continuous effect too. Its Duração clause says only "Efeitos contínuos", unlike its damage
  clause.
- ⚠️ A Condição with no stated nature (a Magia's Amaldiçoado, a bare Envenenado) is not shortened.
