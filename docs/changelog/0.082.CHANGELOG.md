# Changelog — aventyrs-core 0.0.82

**Ego spending — Phase 9: Ego at zero.** Plan in `docs/plans/ego-spending-plan.md`.

## New

- `ego.EgoSetback` — the three 1d6 tables (Sorte, Iniciativa, Autocontrole; Recursos has none), `of(domain, face)`.
- `CombatantSheet#getOwedEgoSetbacks()` (Egos whose permanent points reached zero, having had some, not yet rolled),
  `#recordEgoSetback`, `#getEgoSetback(domain)` (only while the Ego is at zero), `#hasEgoSetback`.
- `character.services.EgoSetbackService#rollSetback(sheet, domain, face)` — the caller's d6; `NO_EGO_SETBACK_OWED`,
  `INVALID_DIE_ROLL`.
- `InitiativeEntry.LAST_IN_ORDER`, `CombatantSheet.INSUCESSO_THRESHOLD`, `AbstractSkillInteraction.AZARAO_MARGIN`.

## What each entry does

- **Sorte**: Superficialidade — critical successes read as none (`AbstractSkillInteraction`), its attacks fire no
  Corrente (`AttackDelivery`); Azarão — a failure by ≥ 5 is a Falha Crítica Menor (a Perícia roll, and a defence in
  `AttackReceiver`); Insucesso — the roll's 1d6 check (`getBlindCheckThreshold`), failing on 2 or less; Atrair a
  Morte — the Corrente margin against it is 0; Escárnio de Tykhé — recorded, not applied (no Perícia Falha Crítica
  table in core); Sorte no Azar — nothing.
- **Iniciativa**: Distração — 0 PA in the Cena's first Rodada; Fraqueza — −1PA in odd Rodadas; Hesitação — no Ações
  Livres; Lentidão — `LAST_IN_ORDER` unless an Iniciativa override holds; Passos Reduzidos — Movimento halved;
  Reflexo Lento — no Reações.
- **Autocontrole** (every face also blocks concentration actions, as a Frenesi does): Enfurecidos — compelled to
  attack the nearest; Centelha Morta — Título activation refused (`ABILITY_ACTIVATION_PREVENTED`); Pânico —
  Apavorado; Regressão Mental — Desprevenido; Torpor — Imobilizado; Vontade Fraca — Corrente margin 0.

## Rulings / readings

- Table rulings (2026-09-30): an Ego is at zero when its permanent points are; the setback lasts until it has a
  permanent point again (a received temporary point at zero is only an extra), and falling to zero again rolls again.
- ⚠️ Readings: Azarão's "Erros Críticos" = a Falha Crítica Menor; Regressão Mental = Desprevenido; Torpor =
  Imobilizado; Insucesso shares the Cego's check die (a failure stays a failure, so checking every roll is the same).
- Not applied: Escárnio de Tykhé's effects; Centelha Morta's "qualquer Habilidade ativa é encerrada" (active
  Título effects carry no common marker to end them by).
