# Changelog — aventyrs-core 0.1.7.19

**MobilidadeFeat wiring, Phase 2: SE MOVER E ATACAR and INVESTIDA AQUÁTICA's first clause.**

## New

- **`Feat#resolveRoundMovementIncrease(int, Character, CombatantSheet holder)`** — the sheet-aware form, defaulting to
  the two-argument one; `MovementService#getMovementBase(CombatantSheet, int)` calls it.
- **`CombatantAction#manoeuvre`** (a new trailing component; the eight-argument constructor stays) and
  **`#succeededAt(Manoeuvre)`**. `AttackDelivery`'s recorded action carries the roll's manoeuvre.

## Talentos now real

- **Se Mover e Atacar** (table ruling 2026-10-17) — Vantagem on every attack roll once the holder has travelled 3UD
  or more this Turn; +2UD per Ponto de Ação on the first movement bought after the Turn's latest action, when that
  action was an attack roll.
- **Investida Aquática** — -1PA on an attack when the Turn's latest action is a successful Atletismo roll for
  `Manoeuvre#NADAR`. The 1PA floor holds.
