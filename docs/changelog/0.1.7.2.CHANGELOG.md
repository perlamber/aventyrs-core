# Changelog — aventyrs-core 0.1.7.2

**The Corrente/resistance bridge for Habilidades Monstruosas.** Phase 1 of `docs/plans/monster-manual-v19-revision-plan.md`.

- New `MonstrousAbility` hooks: `resolveAttackEffectChains`, `resolveEffectChainResistanceIncrease`,
  `resolveTargetEffectChainResistanceReduction`, `resolveAttackDamageRetype`, `resolveAdditionalCriticalEffects`. Each
  receives the holder's sheet, so an Efeito Ativo's window ("Neste Turno …") is read off a running `SourcedState`.
- `MonstrousAbilityGrant.heldBy(Character)` and its static scans read them **off the Character**, because a live scene
  foe is a plain `CharacterSheet` built from its blueprint, not a `MonsterSheet`. They are consulted by
  `AttackDelivery`/`AttackEffectsPreview` (Correntes), `EffectChainService#getRequiredMargin` (both resistance
  hooks), `AbstractSkillInteraction` (retype, after every Talento) and `CriticalEffectResolver` (extra crits).
  `MonsterSheet#getAttackEffectChains` stays the fixed-stat-block path, so nothing is applied twice.
- `effect.monstrous` holds the Correntes de Efeitos Monstruosas; `Ofuscar` is the first (cumulative −1PA target /
  +1PA monster). `CireneiaAbility#OFUSCAR` is now applied: its passive −2 Resistência, the active's window, and
  always-on from Abominação.
- "Apenas uma vez por Cena" Efeitos Ativos also reset in `CombatantSheet#startNewScene()` (they used to reset only in
  `MonsterSheet#beginScene`, which a plain scene sheet never runs).
