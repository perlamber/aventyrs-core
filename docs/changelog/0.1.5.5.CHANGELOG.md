# Changelog — aventyrs-core 0.1.5.5

**A Scene can be rebuilt in an order it is handed.**

## Added

- **`Scene#restoreParticipantInOrder`** — `restoreParticipant`, but the sheet goes after everyone restored so far
  instead of at its sorted spot. The client rebuilds its Scene around aventyrs-api's stored turn order with it. The
  server owns that order; re-sorting on the client weighed each controlled sheet's own Iniciativa bonuses and
  Lentidão, which only that client can see. Two clients could then disagree on whose Turn the shared cursor named.
  After the cursor is restored, a participant still waits for the next Rodada, and that boundary sorts the order
  again as before.
