# Changelog — aventyrs-core 0.0.71

**Antecedentes.** `docs/rules/antecedentes.txt` (imported from *V19 Antecedentes - 20250610*) is now
modelled end to end: every character picks one Naturalidade and one Carreira, last in creation.

Table rulings (2026-09-28): picked last; "Se treinado em X" = trained in X at pick time, the
Antecedente's own +1 included; "+1 Graduação" stacks (untrained → 1, no creation slot spent); an Ego
+1 is a full base point (counts for the Vantagem de Ego threshold); "uma vez por dia" renews on a
Descanso Longo, "uma vez por semana" is once per Sessão; Eremita's "Empatia Monstruosa" is the Perícia
Empatia Selvagem; Estudioso Arcano's Semente/Broto are cast paying PM without opening the Árvore;
Vastare picks PD or PM at each Descanso; Caçador's "animais e monstros" = ANIMAL or MONSTRUOSO targets.

Graduação discounts stack and may make a Graduação free (0 EXP, never negative).

Readings (confirmed 2026-09-28): Trombadinha grants
one Especialização; Atleta's "primeiro a agir" = winning initiative; Tolerância Marcial is the first hit
taken in the Cena; Retribuição Atroz remembers damage dealers for the current Cena; Ação Rotineira
renews on any Descanso Longo, Verdadeiro or not.

## New

- **`org.aventyrs.core.background`**: `Background` (sealed), `OriginBackground` (10), `CareerBackground`
  (22), `BackgroundKind`, `GraduationGrant`, `TraitGrant`, `AcquiredBackground`, `Backgrounds` (catalog,
  `byName`). The "não disponível" Naturalidades are not listed.
- **Creation**: `CharacterCreationService#getBackgroundOptions`, `getBackgroundTraitGrants`,
  `getBackgroundBenefitChoices`, `applyBackground`, `applyBackgrounds` — `INVALID_BACKGROUND_SELECTION`.
  Applying returns a new `Character` with the grants materialized.
- **`Character`**: `backgrounds` (`@Singular`), `getBackground(BackgroundKind)`, `getCastableSpells()`;
  `getFeats()` now also returns each held Antecedente's Benefício.
- **`feat.AntecedenteFeat`** — the 32 Benefícios (`getBenefitName()`, `isRollActivated()` for the seven spent on a roll); `FeatCategory.ANTECEDENTE` / `FeatCategory.Type.ANTECEDENTE`,
  excluded from `FeatCatalog`.
- **`Feat` hooks**: `onActivationRecorded`, `resolveEgoDepletionGrant`, `resolveGraduationCostReduction`,
  `getGrantedCastableSpells`, `resolveTrueRestBonus`, `resolveRestBonusChoices`, `resolveChosenRestBonus`.
- **`skill.SkillTraitCatalog`** — `specializationsOf`, `competencyAbilitiesOf`, `traitsOf`.
- **Rest**: `RestService#getRestBonusChoices`, `applyRest(…, boolean verdadeiro, ResourceType chosenBonus)`.
- **Creatures**: `CreatureType.ANIMAL`; `MonsterTemplate#getCreatureType()` (default MONSTRUOSO),
  `MonsterBlueprint#creatureType`, `CombatantSheet#getCreatureType()`.
- **Sheet**: `CombatantSheet#wasDamagedByThisCena(UUID)`, `getHitsReceivedThisCena()`.
- `CharacterEgos#withBaseBonus`.

## Changed

- `CombatantSheet#recordAction` calls `Feat#onActivationRecorded` for each activated Talento.
- The Ego-depletion trigger scans held Talentos as well as Habilidades de Atributo.
- `SkillGraduationService#getUpgradeCost(Character, SkillType)` subtracts Talento discounts (floor 0).
- `SpellFamiliarity` reads `Character#getCastableSpells()`.

## Not modelled (TODO'd on the constants)

## Consumers

Persist `Character#getBackgrounds()` (Antecedente id, graduation skills, trait ids, benefit picks) and
restore it with the builder's `.background(…)` — **don't** call `applyBackground` again on load. A
persisted foe restored from numbers reads as MONSTRUOSO unless its blueprint is kept.
