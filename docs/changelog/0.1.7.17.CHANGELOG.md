# Changelog — aventyrs-core 0.1.7.17

**MobilidadeFeat wiring, Phase 0: a per-Turn movement ledger** (`docs/plans/mobilidade-wiring-plan.md`).

## `CombatantSheet`

- **`recordDistanceMoved(int ud)` / `getDistanceMovedThisTurn()`** — the UD travelled this Turn, by every kind of
  movement (Pontos de Ação, a manoeuvre, Reposicionar, Investida, a granted move). Caller-stated, since this core does
  no geometry. Reset by `startTurn`.
- **`hasMovedThisTurn()`** — a movement bought, a Reposicionar declared, or any distance recorded.
- **`getMovementsAtLatestAction()`** — `getMovementsTakenThisRound()` as it stood when this Turn's latest action was
  recorded; `-1` before any. A movement whose index equals it is the first one bought after that action.
