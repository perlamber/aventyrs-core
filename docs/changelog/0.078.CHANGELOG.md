# Changelog — aventyrs-core 0.0.78

**Ego spending — Phase 6: Sorte.** Plan in `docs/plans/ego-spending-plan.md`.

## New

- `ego.SorteEffect` — what a Ponto de Sorte does to one Perícia roll, each with the point type it costs:
  - `REROLL_WITH_ADVANTAGE` (temporary) — new dice, `+Skill.ADVANTAGE_BONUS`.
  - `DIFFICULTY_REDUCTION` (temporary) — the GD eased by `SorteEffect.DIFFICULTY_REDUCTION_LEVELS` (1); reported
    unapplied on an attack against a Defesa, like every GD reduction there.
  - `FORCED_SUCCESS` (permanent) — the roll succeeds "independente do resultado dos dados" (the Cego 1d6
    included), as an Acerto Crítico Menor (an Acerto Crítico Maior the dice gave stays). An attack hits, a
    defence holds.
  - `UNLEASHED_CRITICALS` (permanent) — on a hit, the Corrente fires whatever the margin and the Efeitos Críticos
    apply at Maior severity; on a successful defence, the Efeitos Críticos Defensivos apply, at Maior.
- `SkillRoll#withSorte(effect)`, `#rerolledWithSorte(newDice)`, `#getSorteEffects()`, `#hasSorte(effect)`.
- `EgoPointsService#applySorte(sheet, roll, effect)` / `#rerollWithSorte(sheet, roll, newDice)` — pay one Sorte
  point of the effect's type through `useEgoPointsForEffect` (Às na Manga follows) and return the marked roll to
  resolve again. `NOT_ENOUGH_EGO_POINTS` with nothing spent when the point isn't there. No timing gate.

## Rulings / readings

- ⚠️ "Reduzir o GD" gives no amount — read as 1 nível. The Narrador's approval ("contra um PdN") is the gate.
- ⚠️ A chosen success overrides the dice only: a Defeito's automatic failure, an immunity, and a defence Trava
  Mental forbids still hold.
- ⚠️ "Desencadear … Efeitos Críticos Maiores" is read as the effects alone: the roll's `CriticalResult` is
  reported as rolled, so it grants no Vantagem em Danos and no "Sucesso Crítico Maior" trigger (Destino
  Favorável). Frenesi Assustador's suppression still wins.
- The scene changes are narrative — `useEgoPointsForEffect` with no effect.
