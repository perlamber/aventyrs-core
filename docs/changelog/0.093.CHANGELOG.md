# Changelog — aventyrs-core 0.0.93

**Judging a cast** — step 1 of `docs/plans/spell-casting-audit.md` (core half).

## New

- **"Pessoal ou Toque"**: `SpellCastingService#castSpell` accepts a target that fits either of the version's two
  targetings (`Spell#getAlternateTargeting`).
- **`SpellCastingResult#castingTargetValue`**: the GD's value, raised to the target's DM for an "ou DM do Alvo
  (maior)" version (⚠️ never against the caster's own DM).
- `#castVersion` reports the version actually cast.
- **`SpellCastingService` gains four methods:**
  - `castSucceeds(result, total)`;
  - `isEffectChainTriggered(result, target, total)` — the target's Corrente margin, Resoluto included;
  - `resolveEffectChain(version, caster, roller)`;
  - `resolveCastingCriticalEffect(version, caster, castingRoll, roller)` — Amenizar, Imunizar, Potencializar…
- **`SpellChainKind`** (`Spell#getEffectChainKind`, not inherited by an Efeito Alternativo): Sobrecura on Revigorar,
  Benção Bifurcada, Revigorar Maior, Cura em Massa and Nova Rejuvenescedora.
