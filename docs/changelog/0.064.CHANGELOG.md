# Changelog — aventyrs-core 0.0.64

**Damage types** (plan Phase D). Each reduction now reaches only the damage its rules text names,
RDS is its own stat, Talentos can hold immunity / scoped Meio-Dano / Resistência Elemental, "seu
elemento" is readable off the Raças Elementais, and a Talento can retype an attack.
Feat TODO lines: 274 → 269.

Per `docs/rules/defesas-e-resistencias.txt`, this is what each reduction now reaches:
- **RD** (−2 per instance): only a `FISICO` hit, or one the caller left untyped.
- **RDS** (−1 per instance): every hit but a `PRIMORDIAL` one, physical or magical.
- **RM**: only a `MAGICO` hit.
- **RE**: an elemental hit of the element resisted, physical or magical.
- **RA**: every hit.

## Changed — behaviour

- **A magic, elemental or Primordial hit no longer takes RD.** Before this, RD reached every
  hit, so a `MAGICO` hit took RD *and* RM.
- **RDS is no longer RD.** `ModifierType.DAMAGE_TAKEN_REDUCTION` is new, and every source whose
  rules text says RDS was moved to it:
  - Talentos: `MonstruosoFeat#PELE_RIJA` (2), `AssassinoFeat#ESCUDO_DE_SOMBRAS` (3),
    `TrollFeat#REGENERACAO_REATIVA_INVERNAL`, `ElementalFeat#TRANSFORMACAO_ELEMENTAL` (1), both
    `GorgonaFeat` Proteções (1);
  - `ArtesAprimorarComArteAbility`'s Esquiva e Aparar branch;
  - Cruz de Sangue's Malícia de Valentão (2);
  - Santo's Bastião dos Necessitados (the Título RD pair is RDS now);
  - the Mutante Monstruoso, Besta Alada and Brotos de Mapinguari RDS instances.
- **A numberless "recebe RDS" is one instance, worth 1** (`DamageService#DAMAGE_TAKEN_REDUCTION_INSTANCE`).
  Before this it was worth 2, as RD. This affects `ElementalFeat#TRANSFORMACAO_ELEMENTAL` and the
  Górgona Proteções.
- `GorgonaFeat#PROTECAO_DO_DEUS_DOS_MONSTROS`' "RDS e RD" now grants both (RD 2 and RDS 1). It was
  read as one grant before.
- `sheet.PeleDePedra`'s "RDS 5" skips Primordial damage.
- `DamageService#getTotalDamageReduction(sheet, type, source, sceneContext)` no longer includes the
  Título RDS scans. Read `getTotalDamageTakenReduction` for those.

## New

- `ModifierType.DAMAGE_TAKEN_REDUCTION`. `MonstrousAbilityGrant` has a `@Modifier` for it.
- `DamageService`:
  - `DAMAGE_TAKEN_REDUCTION_INSTANCE`;
  - `getTotalDamageTakenReduction(Character)`;
  - `getTotalDamageTakenReduction(CombatantSheet, SceneContext)`.
- `Feat` hooks:
  - `resolveDamageTakenReduction(Character[, CombatantSheet])`;
  - `resolveElementalResistanceInstances(element, character, holder)`;
  - `halvesDamage(type, descriptor, character, holder)`;
  - `isImmuneToDamage(type, descriptor, character, holder)`;
  - `resolveDamageRetype(attacker, attackSkill, attackSource)`.

  The first four are folded into the sheet's existing immunity, Meio-Dano and RE queries.
- `InteractionResult#getRetypedDamage()`: the type the roller's Talentos make this attack deal.
- `AbstractMesticoRace#getElement()`: "seu elemento", per the Talentos Elementais' table. Colosso
  Terra, Aquan Água, Dólos Vento, Flaminídeo Fogo, Invernal Gelo, Nascido da Floresta Natural,
  Agástia Trovejante Eletricidade, Agástia Vulcano Magma.

## Now real

- `ElementalFeat`:
  - `#RESISTENCIA_ELEMENTAL`: RE against the holder's element. ⚠️ It applies from the first hit
    too, since the first-of-Cena Meio-Dano is not modelled.
  - `#RESISTENCIA_ELEMENTAL_SUPERIOR`: that element's hits are halved. The first-of-Cena zeroing
    is still TODO.
  - `#IMUNIDADE_ELEMENTAL`: immunity to that element.
  - `#ARCANISMO_ELEMENTAL`: 0.5 EXP off Magias of that element.
- Metamorfose Dracúlea's **Névoa**: immune to physical damage except Fogo. ⚠️ The "armas de
  Dyospiros" exception is not honoured.
- `OrquicoFeat#PALADINO_DE_EPONA`:
  - weapon attacks retype to Físico Elemental: Terra;
  - Divina / Terra Magias delivered as attacks retype to Físico;
  - "+½ Vigor" is added to weapon dano.
- `FeralFeat#DESPREZO_NATURAL`: Arma Natural attacks retype to Físico Elemental: Natural.

## Callers

- When applying an attack's damage, use `InteractionResult#getRetypedDamage()` in place of the
  attack's own type when it is present.
- Type your hits. An untyped hit is still read as plain physical (RD and RDS), but a Magia's
  damage passed untyped now over-mitigates in the other direction.
- A display of "RD" should show `getTotalDamageReduction` and `getTotalDamageTakenReduction`
  separately.
