# Changelog — aventyrs-core 0.1.5.4

**The Graduação cap answers for untrained Perícias too.**

## Changed

- **`SkillGraduationService#getMaxGraduation`** no longer requires the Perícia to be trained. An untrained one gets
  the cap it would grow under: 2 × the base of its key Atributo (`skillType.newSkillInstance()`), or of the
  substituted Atributo when the holder has a matching `SkillCompetencyAbility`/`PeritoTeoricoAbility`. Before,
  it threw `RollErrorException`. The client's creation wizard and character hub use it for every Perícia now.
- Table rulings recorded (2026-10-08): the cap counts the **base** only, with no racial bonus and no variable; a
  substitution **always** governs the cap, even when the substitute Atributo is the lower one; going over the
  cap at creation is **warn-only**, and `CharacterCreationService` doesn't refuse it.
